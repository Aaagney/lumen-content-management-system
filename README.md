## 🚀 Setup Steps

1. **Database Import:**
   - Start Apache & MySQL in XAMPP.
   - Open `http://localhost/phpmyadmin`.
   - Import `database/database.sql`.

2. **Backend Server:**
   ```bash
   cd server
   npm install
   npm run dev
